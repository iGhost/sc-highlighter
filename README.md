# Highlight My Items

**Highlight My Items** — утилита для **Star Citizen**, позволяющая изменять цвет наименований предметов в игре на основе пользовательских списков.

![Main application window](https://cp.expanseunion.com/media/highlighter_main_window_thin.png)

Утилита работает путём модификации файла `global.ini` и предназначена для упрощения поиска и визуального выделения нужных предметов, руды и объектов.

## Возможности

- Подсветка предметов по пользовательским спискам
- Поддержка нескольких списков
- Выбор цвета выделения
- Резервное копирование `global.ini`
- Восстановление исходного `global.ini`
- Простая визуальная индикация успешных операций

---

## Требования

- Файл `global.ini` для соответствующего языка в директории `data\Localization\[язык]`
- Если в `user.cfg` указан `g_language`, утилита использует эту локализацию; иначе используется `english`

---

## Установка

1. Скопируйте файл `highlighter.exe` в папку игры: StarCitizen\LIVE\
2. Запустите `highlighter.exe`.

При первом запуске будет создан каталог `highlights` для пользовательских списков предметов.

Каталог `_backup` будет создан после нажатия **[ Backup global.ini ]**.

---

## Первый запуск (обязательно)

1. Запустите `highlighter.exe` **из папки `StarCitizen\LIVE`** .
2. Нажмите кнопку **[ Backup global.ini ]** — будет сохранена актуальная версия файла global.ini.
3. Отметьте чек-боксом нужный файл в списке.
4. Нажмите **[ Highlight ]** для применения изменений.

### Индикация кнопок
- 🟢 **Зелёный** — операция выполнена успешно  
- 🔴 **Красный** — произошла ошибка

---

## Проверка работы в игре

Подсветка применяется:
- при захвате предметов лучом в FPS,
- при просмотре руды через **ATLS GEO**,
- при корабельном сканировании («пинге») объектов.

---

## Списки предметов

### Формат списков

- В папке `highlights` хранятся пользовательские списки.
- Файлы формата `*.txt`
- В тексте **один ключ - одна строка**
- Ключи берутся из `global.ini`

Пример: 
```
items_commodities_bexalite
items_commodities_carbon
items_commodities_copper
```


### Создание собственного списка

1. Создайте текстовый файл (`iloveburrito.txt`)
2. Поместите его в папку: StarCitizen\LIVE\highlights
3. Укажите в нём ключи нужных предметов, например: 
   ```
   item_NameFood_burrito_01_a
   item_NameFood_burrito_01_beef_a
   item_NameFood_burrito_01_chile_a
   ```
4. Сохраните файл `iloveburrito.txt`
5. Запустите утилиту и отметьте список в интерфейсе
6. Запустите игру

---

## Восстановление global.ini

1. Запустите `highlighter.exe` **из папки `StarCitizen\LIVE`** .
2. Нажмите кнопку **[ Restore global.ini ]** — будет восстановлена последняя сохранённая вами резервная копия файла `global.ini` для текущего языка.
3. Отметьте чек-боксом нужный список предметов.
4. Выберите цвет в выпадающем списке
5. Нажмите **[ Highlight ]** для применения изменений.

---

## Удаление
Предварительно нажмите кнопку **[ Restore global.ini ]** — будет восстановлена последняя сохранённая вами резервная копия файла `global.ini`.

_Как альтернатива для восстановления файла global.ini для русской версии - переустановка русификатора Star Citizen._

Для удаления утилиты:
1. Удалите файл `highlighter.exe`
2. Удалите папки: `highlights` ; `_backup`

---

## Решение проблем

Если восстановление резервной копии файла `global.ini` не срабатывает при нажатии кнопки **[ Restore global.ini ]** или не
правильно подцвечиваются элементы в игре - восстановите оригинальный `global.ini`
(_переустановите локализацию для русской версии_) и при следующем использовании программы Highlighter
обязательно нажмите **[ Backup global.ini ]**
